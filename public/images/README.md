# Bilder för Santosh Kumar Website

## Logo
- **Fil:** `logo.svg`
- **Används i:** Navigation (header)
- **Status:** ✅ Redan tillagd

## Hero Image
- **Fil:** `hero-image.jpg` (saknas - behöver läggas till)
- **Används i:** HeroSection
- **Rekommenderad storlek:** Minst 1200x900px (4:3 format)
- **Format:** JPG, PNG eller WebP

## Så här lägger du till hero-bilden:

1. Spara din bild som `hero-image.jpg` i denna mapp (`/public/images/`)
2. Alternativt, om du har bilden med annat namn:
   - Döp om den till `hero-image.jpg`
   - Eller uppdatera sökvägen i `components/sections/HeroSection.tsx`

## Kontrollera att bilderna fungerar:

1. Öppna http://localhost:3000 i din webbläsare
2. Logo ska synas i navigationen (överst till vänster)
3. Hero-bilden ska synas i hero-sektionen (om filen finns)

## Felsökning:

Om bilderna inte visas:
- Kontrollera att filerna finns i `/public/images/`
- Kontrollera filnamn (skiftlägeskänsligt)
- Ladda om sidan (Cmd+R eller Ctrl+R)
- Kontrollera konsolen för felmeddelanden (F12)
